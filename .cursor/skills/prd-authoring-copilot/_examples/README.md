# Approved PRD examples

Drop 1–2 approved past PRDs in this folder to act as a quality bar for new ones. The Cursor rule (`.cursor/rules/prd.mdc`) references this directory so the agent can pattern-match against your team's actual style, not generic templates.

Recommended:

- Pick PRDs that shipped successfully and were considered well-written internally.
- Keep them as `.md` files. Strip anything confidential before committing.
- Update the set every 6–12 months as your team's standards evolve.

Filename convention: `<initiative-slug>-prd.md` (e.g., `checkout-redesign-prd.md`).
