# Lightweight Example Prompts

Use these prompts to quickly validate trigger coverage and prompt flow.

## PRD from scratch

1. "Write a PRD for reducing checkout abandonment in our mobile app."
2. "Draft a PRD for improving order status visibility after purchase."

## Shared artifacts path flow

3. "Help me draft a PRD using our shared artifacts folder at `\\team-drive\\product\\research\\q2`."
4. "Create a PRD from research in `https://company.sharepoint.com/sites/product/research/loyalty`."

## No shared path flow

5. "I do not have a shared artifacts location. Please draft a PRD from what I provide here."
6. "No shared folder. Use this summary and ask me what is missing before drafting."

## Gap-clarification behavior

7. "We should improve onboarding. Draft a PRD."  
   (Intentionally vague to test targeted clarification questions.)
8. "Write a PRD for restaurant pickup optimization. Keep questions minimal."

## PRD refinement / review

9. "Review this PRD draft and identify gaps, unclear requirements, and missing non-goals."
10. "Refine this PRD to make requirements testable and success metrics measurable."

## PRD to Jira Epic conversion

11. "Convert this approved PRD into Jira-ready epics with acceptance criteria."
12. "Create one Jira epic from this requirement set and include scope and non-goals."
